# Asar boots — сайт-магазин

Мобильный лендинг с каталогом, корзиной, оформлением заказа и обратным звонком. Статика + одна serverless-функция на Vercel.

## Что править

- `data.js` — контакты (телефон, WhatsApp, Instagram), цены, остатки по размерам, ID пикселя Meta.
- `index.html` — тексты.
- `img/` — фото (`{цвет}-main/side/back.webp`).

## Заявки

Форма шлёт POST на `/api/order`. Чтобы заявки приходили в Telegram, в настройках проекта Vercel добавьте переменные:

- `TELEGRAM_BOT_TOKEN` — токен бота из @BotFather
- `TELEGRAM_CHAT_ID` — id чата или группы

Без них заявка пишется в логи Vercel, а покупатель после оформления получает кнопку «Открыть WhatsApp с заказом» с готовым текстом.

## Локально

npx vercel dev
